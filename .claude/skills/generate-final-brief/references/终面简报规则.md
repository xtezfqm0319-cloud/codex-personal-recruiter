# 终面简报规则

> 项目尚未提供独立的既有终面简报 Prompt。本文件按 V1.0 架构基线实现首版规则；收到真实 Prompt 后在此替换并保留变更记录。

## 信息优先级

1. 正式岗位画像和公司通用标准。
2. 原始简历、原始面试纪要与 HR 明确补充事实。
3. 已人工确认的结论。
4. AI 分析报告和倾向性判断。

若材料冲突，列出双方来源、冲突内容和需验证方式，不自行消除冲突。

## 写作要求

- 根据候选人年限调整期待：年限较短侧重潜力和学习证据，资深候选人侧重复杂度、影响范围和可复现结果。
- 每个关键判断附近提供材料路径和具体证据；不得只写“能力强”“匹配度高”。
- 明确标记“已确认事实”“AI 判断”“未验证项”。
- 单独说明哪些已确认个人偏好影响了判断；没有适用偏好时明确说明。
- 不大段复述简历，不制造精确评分，不替代录用决定。
- 终面问题必须对应关键风险、材料冲突或未验证项。
- 开头必须使用 `建议进入录用讨论`、`谨慎推进`、`继续验证` 或 `不建议推进` 给出一个清晰倾向。
- 紧接倾向列出三条决定性理由、最大下行风险，以及最可能改变当前倾向的一项新证据。
