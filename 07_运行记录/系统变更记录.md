# 系统变更记录

## 2026-07-21｜建岗提示词完整版

- 在核心 `create-position` Skill 之外增加详细判断与输出规范，固定第一轮回复、决定性问题和选人规则预览格式。
- 补充证据强弱、验证阶段、取舍与替代规则、正反示例和写入前自检，提升不同会话下的岗位画像稳定性。
- 同步更新岗位模板；现有正式岗位画像保持不变，新结构只用于后续建岗或用户主动重新校准。

## 2026-07-21｜建岗提示词准确性优化

- 经用户确认，将 `create-position` 从“整理岗位画像”升级为“建立选人决策模型”。
- 建岗交互改为先给判断、后提问，每轮最多三个决定性问题，并为问题附上影响和推荐默认值。
- 正式岗位画像开始要求明确准入、能力底线、排序因素、取舍规则、证据强弱和验证阶段。
- 根据用户反馈将完整建岗提示词改为中文，并将“后续逐环节提供中文改写和完整前后对比”写入长期执行规则。
- 已有正式岗位画像不自动修改；新规则从后续建岗和用户主动重新校准时生效。

## 2026-07-21｜Codex 与 Claude Code 双端兼容

- 新增 `CLAUDE.md`，通过 `@AGENTS.md` 复用同一套长期招聘规则和权限边界。
- `.agents/skills/` 继续作为唯一维护源，新增同步工具生成 `.claude/skills/` Claude Code 项目 Skills。
- Claude Code 兼容版本自动把 Skill 间的 `$skill-name` 调用转换为 `/skill-name`，并保留全部参考材料。
- 新增自动化测试，防止两端 Skill 名单、内容和调用方式漂移。

## 2026-07-20｜V0.3 个人招聘助理体验升级

- 经用户确认新增 `个人招聘判断偏好.md`；具体招聘偏好仍需逐条确认，不从单个决定自动推断。
- 日常交互改为结论优先、自然语言优先，默认隐藏例行文件操作过程。
- 新增今日招聘简报、岗位候选人比较、候选人面试准备和偏好学习机制。
- 现有简历、面试、终面和历史人才 Skills 开始继承已确认个人偏好。

## 2026-07-17｜本地 OCR 与文本完整度检测

- PDF 改为逐页检查文本层质量，对低文本且存在视觉内容的页面执行本地 OCR。
- 默认使用本地 RapidOCR ONNX 模型，macOS 可回退 Apple Vision，其他环境可回退 Tesseract；不调用外部模型 API。
- 简历与面试纪要建档时保存独立质量报告；OCR 后仍不完整的材料进入待确认区。
- 文本完整度仅是提取技术指标，不作为候选人评分。
